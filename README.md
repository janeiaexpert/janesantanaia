# Link & Bio Studio

Crie um mini site moderno para colocar na minha bio do Instagram. As cores deve serem igual a paleta da imagem em anexo e a foto do perfil é da imagem em anexo o link deve estar pó trás da imagem do Nome Guia fácil crie um painel para o administrador acessar. 

Uso,Fonte Principal,Fonte Secundária (Alternativa),Estilo
Títulos (Headlines),Montserrat ,Poppins ,"Sans-serif elegante, moderna e legível. "
Subtítulos,Poppins ,Montserrat ,Suave e moderna. 
Corpo do Texto,Inter ,"Simples, Legível",Simples e legível. 

Dica de Estratégia: Use o Montserrat ou Poppins (ambas são Sans-serif, que são claras e modernas ) para os títulos e intertítulos, garantindo um visual profissional e confiante. Mantenha o corpo do texto na fonte Inter para máxima legibilidade, pois sua marca precisa ser clara antes de ser bonita.

Lembrete de Estilo Visual: O estilo geral da sua marca é clean, leve, feminino, espaçado, moderno e profissional.  As fontes devem refletir essa sensação.
